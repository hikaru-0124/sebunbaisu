# セブンヴァイス — ブラウザ版

提供されたカード画像を使った、3〜4人用のブラウザ版です。友人3〜4人との通信対戦と、人間1人＋CPU2〜3人のCPU対戦で遊べます。

## 起動

Node.js 20以降を使用します。ゲーム本体には外部パッケージが不要です。

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。Codespacesの場合は「ポート」タブで3000番のポートをブラウザで開きます。ポートを変える場合は `PORT=3001 npm run dev` を使えます。

## 操作

### 通信対戦

1. トップ画面の「友人と通信対戦」でプレイヤー名と人数を入力し、「ルームを作る」を選びます。
2. 6桁の招待コードか「招待リンク」を友人に共有します。友人は自分の名前を入力して参加します。
3. 全員がそろったらルーム作成者が「対戦を開始する」を選びます。
4. 自分の手番でカードと効果の対象を選びます。全員の画面に同じカード演出が表示され、全員の確認が終わってから続行します。
5. 次のラウンドと再戦はルーム作成者が開始します。

各プレイヤーの画面では自分を下側に配置し、時計回りの席順を保ちます。サーバーは本人の手札だけを送り、他人の手札と山札のカード内容を送信しません。手番や得点はサーバーで検証します。

ページを再読み込みすると同じ席に復帰します。タブを閉じた後も、同じブラウザで「前のルームに戻る」から復帰できます。通信が切れると再試行し、15秒以上応答がない参加者がいる間は進行を止めます。「確認して進む」を選んだ人がいる場合は、その人が「次へ」を押すまで全員が待ちます。

「退出」はその対戦を終了して残ったメンバーを待機室へ戻します。作成者が退出した場合は次の参加者が作成者になります。新しい参加者を補充して、対戦を開始できます。

全員が同じサーバーURLにアクセスしてください。Codespacesで友人と遊ぶ場合は、「ポート」タブで3000番の表示範囲を「公開」にし、表示された転送URLを使います。自分のPCの `localhost` のURLは他の端末からは使えません。LANではサーバーを実行するPCのIPアドレスとポートを使います。

ルームはサーバーのメモリに保持しています。**サーバーを停止・再起動するとルームは消えます。** 4時間通信がないルームも削除されます。常時公開する場合はNode.jsサーバーを継続稼働させてください。静的ファイルだけのホスティングでは通信対戦APIは動きません。

### CPU対戦

1. 3人または4人を選び、対戦を開始します。先手はランダムです。
2. 自分の手番でカードをクリックし、「このカードを出す」を選びます。
3. 憤怒・嫉妬・強欲・暴食は画面の選択肢から対象を選びます。
4. 得点者が出たら「次のラウンドへ」。先に3点獲得した人が勝者です。

場のカードをクリックすると効果を確認できます。対戦の進行はブラウザに自動保存され、トップ画面から再開できます。保存できないブラウザでもプレイできます。CPU速度は画面上部で変更可能です。

カードを出すと、誰が何を出したかを中央に大きく表示します。奪取・交換・山札からの獲得・追加手番・得点は別の表示で順に確認できます。カードはプレイヤーの場から中央へ飛び出し、結果の確認後に関係する場を強調します。直前の行動も卓上に残ります。

演出の下にある「演出の進め方」で、自動の通常表示・ゆっくり表示・「確認して進む」を選べます。「次へ」で早送りできます。確認して進むモードでは押すまで次の処理へ進みません。別のタブを見ている間やルールを開いている間もCPUを止めます。

## ルール

詳細は `docs/rules.md` と画面の「遊び方」を参照してください。憤怒はユーザーが訂正したルールを採用しています。未指定の裁定は `docs/rules.md` の実装上の裁定に記載しています。

CPUは相手の非公開手札を参照せず、公開された場と自分の手札から選択します。

## 検証

```bash
npm test
```

カード効果、山札切れ、得点、100試合のCPUシミュレーション、20試合の通信対戦シミュレーション、非公開手札、手番・作成者の権限、確認待ち、退出・再接続を検証します。

実際のブラウザ操作を検証する場合は、開発用パッケージとChromiumを準備し、開発サーバーの起動中に実行します。

```bash
npm install
npx playwright install --with-deps chromium
npm run test:browser
npm run test:online
```
