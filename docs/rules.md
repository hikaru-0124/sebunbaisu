# セブンヴァイス：提供された画像から確認したルール

参照画像：`images/20200206_0f8494.jpg`、`images/20200206_db4745.jpg`。
実装用に内容を整理したもの。画像は2018年表記のルールであり、他の版との差異は未確認。

## 構成・準備

- 3〜4人。7種類のカードが各5枚、合計35枚。
- 全カードをシャッフルし、各プレイヤーに1枚ずつ配る。手札は本人だけが確認できる。
- 最初のスタートプレイヤーはじゃんけんで決める。

## 手番

1. 山札から1枚引く。
2. 手札2枚のうち1枚を自分の場に表向きで置く。
3. 置いたカードの効果を処理する。
4. 得点者が出るまで、次のプレイヤーが同じ手順を繰り返す。

効果で場に移動したカードの効果は発動しない。各効果に書かれた対象・枚数の扱いを実装する際、選択必須か任意かなど、画像に明記されていない細部は別途確認する。

## カード効果

| カード | 処理 |
| --- | --- |
| 憤怒 | 他プレイヤーの手札1枚を自分の場に移し、取られたプレイヤーはすぐに山札からカードを補充する。 |
| 嫉妬 | 他プレイヤーの場のカード1枚と、自分の手札を交換する。 |
| 強欲 | 他プレイヤーの場からカード1枚を選び、自分の場へ移す。 |
| 傲慢 | 自分の手番をもう一度行う。追加の手番で出したカードの効果も処理する。 |
| 色欲 | 山札の一番上のカード1枚を自分の場へ移す。 |
| 暴食 | 右隣のプレイヤーの場から、同じ種類のカードを最大2枚選び、自分の場へ移す。異なる2種類を選ぶことはできない。 |
| 怠惰 | 直前のプレイヤーが使った効果を使う。自分が直前に傲慢を使っていた場合は、追加の手番を行う。 |

## 得点・終了

- 自分の場で同じ種類を4枚集めると1点。
- 自分の場に7種類をそろえると2点。
- 得点者が出たら、準備から次のラウンドを始める。得点者が次のスタートプレイヤーとなる。
- 合計3点以上を獲得したプレイヤーが勝者。
- 山札が尽きた場合は、手札を追加せず、手札の1枚を場に出す。
- 全員の手札がなくなった時点で得点者がいない場合は、全員無得点として準備からやり直す。
- 次のラウンドでは必ずシャッフルする。

## 実装前に確認する細部

- 効果の途中で得点条件を満たした場合の判定タイミング。
- 対象の手札・場が空の場合の効果処理と、可能な部分だけ処理するかどうか。
- ラウンド最初の手番に出した怠惰が参照する効果。
- 怠惰が直前の怠惰を参照した場合の扱い。
- 全員無得点でやり直す場合のスタートプレイヤー。

## 現在のブラウザ版で採用した裁定

以下は画像に明記されていないため、変更可能な実装上の仮定。

- 効果をすべて処理した後に得点を判定する。
- 対象がない場合は可能な部分だけ処理する。山札が空なら補充しない。
- 手札が残っていない場合の嫉妬は交換しない。
- ラウンド最初の怠惰は効果なし。怠惰が続く場合は元の効果を引き継ぐ。
- 嫉妬で相手のセットが完成した場合も得点する。同時に複数人が条件を満たした場合は、手番プレイヤーから時計回りの順で判定する。
- 無得点でやり直す場合は同じスタートプレイヤー。初回の先手はランダム。
- 時計回りの席順を手番順とし、右隣は一つ前の席。手札がなく山札も空のプレイヤーの手番は飛ばす。
- 効果の対象が存在する場合は選択必須。暴食では同じ種類の1枚か2枚を選択できる。
